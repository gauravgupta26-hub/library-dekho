# 👀 Library Dekho

**City Public Library Membership & Book Catalog System** – a responsive, interactive frontend web app built with HTML, CSS and vanilla JavaScript.

> Presented by **Team Sandworm**

## ✨ Features

- **Splash, Login & Sign Up** – animated 👀 splash screen; simple signup with name, Gmail and address
- **Book Catalog** – 29 books with search and filters for Fiction, History, Science, Literature and Competitive Exam books; click a book for details and a "Go & Read" Wikipedia link
- **Branch Directory** – addresses, reading room seating capacity and operating hours, including LPU Library, Phagwara
- **Membership** – online registration with Student / Senior Citizen concession plans; header badge turns from red *Buy Membership* to green *Member*
- **Find a Library Near You** – choose from 10 states, get 2 random district libraries, add them to your branches
- **Join with Time Slot** – members pick a date and time slot at any branch to complete joining
- **Book Reservation** – hold books at your preferred branch, with a quick link to read about the book
- **Dark / Light Mode** – one-click theme toggle, remembered across visits
- **Help & Reviews** – Telegram support, star rating and Google review option

## 🛠️ Tech Stack

HTML5 · CSS3 (variables, grid, flexbox) · JavaScript (ES6) · localStorage for data
